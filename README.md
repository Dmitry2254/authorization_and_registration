
# 🔐 React Authentication

Простой проект авторизации и регистрации пользователей, созданный с использованием React и React Router.

## 🚀 Технологии

- React
- JavaScript
- CSS3
- React Router DOM
- Vite

## 📁 Структура проекта

```text
├── src/
│   ├── main.jsx
│   ├── Login.jsx
│   ├── Login.css
│   ├── Register.jsx
│   └── Register.css
├── index.html
└── README.md
```

## ✨ Возможности

### Авторизация
- Ввод Email.
- Ввод пароля.
- Показать и скрыть пароль.
- Проверка заполнения полей.
- Проверка длины пароля.
- Переход на страницу регистрации.

### Регистрация
- Ввод имени пользователя.
- Ввод Email.
- Создание пароля.
- Повтор пароля.
- Показать и скрыть пароль.
- Проверка заполнения полей.
- Проверка совпадения паролей.
- Переход на страницу авторизации.

## ⚙️ Установка

1. Склонируйте репозиторий:

```bash
git clone <URL-репозитория>
```

2. Перейдите в папку проекта:

```bash
cd project
```

3. Установите зависимости:

```bash
npm install
```

4. Установите React Router:

```bash
npm install react-router-dom
```

## ▶️ Запуск проекта

Запустите команду:

```bash
npm run dev
```

После запуска откройте адрес, который появится в терминале.
